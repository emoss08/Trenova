## What it's for
Charge types is a reserved page that has not been built yet. It is not in the navigation, and opening it shows only a notice that the page is under construction; nothing can be viewed or set up here.

Extra charges billed on shipments are set up on [Accessorial charges](/billing/configuration-files/accessorial-charges).

## Tasks

### Set up a charge that is billed on shipments
Keywords: charge type, new charge, extra charge, accessorial
1. Open [Accessorial charges](/billing/configuration-files/accessorial-charges) instead; [Charge types](/billing/configuration-files/charge-types) only shows **This page is under construction**.
2. Select **New accessorial charge** and fill in the charge.

## Notes
Opening the page needs read access to charge types.
