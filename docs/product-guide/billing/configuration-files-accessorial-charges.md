## What it's for
Accessorial charges is the list of extra services your organization bills on top of line haul, each with a code, a description and how it is priced. Billing and rating staff set them up here once; they are then picked by name when a charge is added to a shipment or to an item in the billing queue.

The table shows each charge's **Status**, **Code**, **Method**, **Description** and **Rate**.

## Tasks

### Add an accessorial charge
Keywords: new accessorial, create fee, add charge code
1. Open [Accessorial charges](/billing/configuration-files/accessorial-charges).
2. Select **New accessorial charge**.
3. Fill in **Status**, **Code** (for example LUM for a lumper fee) and **Description**.
4. Pick a **Method**: **Flat** for a fixed dollar amount, **Per unit** for a rate per mile, hour, day or stop (then choose the **Rate unit**), or **Percentage** for a share of the line haul.
5. Enter the **Amount** and select **Save** (or **Save & close**).

### Change or retire an accessorial charge
Keywords: edit accessorial, update rate, deactivate charge
1. Open [Accessorial charges](/billing/configuration-files/accessorial-charges).
2. Select the charge's row to open it.
3. Change the fields you need, or set **Status** to **Inactive** to stop using it, then select **Save**.

### Find an accessorial charge
Keywords: search accessorial, filter charges
1. Open [Accessorial charges](/billing/configuration-files/accessorial-charges).
2. Type in the search box, or use **Filter** and **Sort** in the table toolbar to narrow the list, for example by **Method** or **Status**.

## Notes
Viewing the page needs read access to accessorial charges; **New accessorial charge** only appears for people who can create them.
