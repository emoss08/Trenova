## What it's for
**What Desk remembers** lists everything the agents keep about how you and your team work. That covers what you told them to keep in mind, what they saved from your conversations, and what they learned by looking back over their own work. Open it from **Memory** in the Desk sidebar.

Each memory shows who it is for (**Just you**, one of your teams, or the **Organization**), when it was saved and where from, and how many times agents have used it. You can add memories, change their words or who they are for, pause them, forget them, and choose whether agents save new memories on their own or ask you first.

## Tasks

### Teach Desk something
Keywords: add memory, remember this, standing instruction, preference, tell the agent
1. Open [What Desk remembers](/desk/memory).
2. Type the memory into the box at the top that starts "Teach Desk something", the way you would tell a colleague.
3. In the menu next to the box, choose who it is for: **Just you**, one of your teams, or **Organization**.
4. Select **Save**. The new memory appears at the top of the list, highlighted, and agents use it from your next question.

### Find a memory
Keywords: search memories, memory filter, team memories, organization memories
1. Open [What Desk remembers](/desk/memory).
2. Above the list, pick **All**, **Just you**, one of your teams, or **Organization**. Each choice shows how many memories it holds.
3. To find a memory by its words, type in **Search memories**. If nothing matches, the list says **No memories match.**

### Change what a memory says
Keywords: edit memory, fix a memory, wrong memory, reword
1. On [What Desk remembers](/desk/memory), find the memory and select **Edit** (the pencil).
2. Change the words, then select **Save**. To leave without changing anything, select **Cancel** or press Esc.

### Change who a memory is for
Keywords: share memory with team, make memory private, move memory to organization
1. On [What Desk remembers](/desk/memory), open the who-it-is-for menu under the memory.
2. Choose **Just you**, one of your teams, or **Organization**. The change saves as soon as you pick.

### Pause or resume a memory
Keywords: stop using a memory for now, set aside, turn off memory
1. On [What Desk remembers](/desk/memory), select **Pause** on the memory. Agents stop using it, but it stays in the list marked **Paused**.
2. Select **Resume** to let agents use it again.

### Forget a memory
Keywords: delete memory, remove memory, forget this
1. On [What Desk remembers](/desk/memory), select **Forget** (the bin) on the memory.
2. The row changes to **Forgotten. Agents won't use this again.** Select **Undo** on that row to bring the memory back. The row stays until you leave the page.

### See how a memory has been used and why it was kept
Keywords: memory usage, last used, why was this remembered, memory source
1. On [What Desk remembers](/desk/memory), the line under each memory shows when it was saved and where from. That is the conversation's title, or a description such as **Added by you** or **An agent looking back over its work**.
2. The same line shows how many times agents have used the memory and when they last did. A memory no agent has used yet says **Not used yet**.
3. For a memory an agent saved, the lines under its words show why it was kept (**Why**), a little of what was said (**Said**), the memory it replaced (**Replaces**) and, if a newer memory has since taken over, **Replaced by**.

### Choose whether agents ask before saving
Keywords: ask first, automatic saving, memory preference, saving mode
1. Open [What Desk remembers](/desk/memory) and find **Saving new memories**.
2. Choose **Automatically** to let agents save what they pick up and tell you in the conversation. Choose **Ask me first** to have each memory offered to you to keep or turn down.
3. The choice also covers what an agent learns when it looks back over a conversation after it goes quiet.

### Check which memories a reply used
Keywords: used memories, which memories did the agent use, memory in conversation
1. In a Desk conversation, a reply that used memories shows a "Used" line with the number of memories above it. Select it to open the list.
2. Each memory shows who it is for and where it was saved from.
3. Select **Forget** to stop agents using one, and **Undo** to take that back.

### Keep or turn down a memory an agent offers
Keywords: remember this for, keep these steps, not now, suggested memory, learned steps
1. When **Ask me first** is on, an agent that wants to save something asks under its reply whether to keep it, and for whom.
2. To change who it is for, select the underlined words for who it is for and pick from the list. Teams show only when you may share memories with them.
3. To change the words before keeping them, click on them. For steps, put each step on its own line. Enter saves, Shift+Enter adds a line, and Esc cancels.
4. Select **Keep** to save it, or **Not now** to turn it down. Either answer can be taken back with **Undo**.

### Change or take back a memory saved in a conversation
Keywords: undo saved memory, learned steps, saved to memory, edit learned steps
1. Under the reply, a memory an agent saved reads **Saved to memory**. One the agent learned by looking back reads **Learned steps** when it is steps for a task.
2. Select **Edit** to change the words, then **Save**, or **Cancel** to leave them as they were.
3. Select **Undo** to remove it. The card then says **Removed from memory**, and **Undo** there brings it back.
4. Select **Why** to see why it was kept, what was said, and what it replaced. For learned steps, the replaced steps appear under **Before**.

## Notes
- You can always keep a memory for **Just you**. Keeping one for a team or the **Organization** needs permission to create agent memories. Without it, those choices are greyed out.
- Changing, pausing or forgetting a team or organization memory needs permission to update agent memories, and a team memory also needs you to hold that team's role. Memories you can't change show no **Edit**, **Pause** or **Forget** buttons, and their who-it-is-for menu is locked.
- **Saving new memories** is your own setting. It doesn't change anyone else's.
- When an agent looks back over its work, a memory meant for a team or the whole organization is always offered rather than saved straight away, whatever your setting. The same goes for anything learned in a conversation that read outside content. Administrators review memories offered for the whole organization in [AI control](/admin/agent-control).
- A memory a newer one replaced says **Replaced by a newer memory** in the conversation and offers no **Undo**, so the two never apply at once.
