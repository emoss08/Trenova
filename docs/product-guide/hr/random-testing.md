## What it's for
Random testing runs the company's DOT random drug and alcohol testing programme. **Pools** lists
the groups of drivers selections are drawn from, with each pool's draw period, rounds drawn this
year and a warning when it is **Below the DOT minimum**. **Rounds** lists every draw with its
**Round**, **Pool**, **Status**, how many were picked for **Drug** and **Alcohol** against the
target, how many were **In the hat**, and when it was **Drawn**. Figures at the top show
**Owed now**, **Rounds this year**, **Selected this year** and **In the hat**.

Each round keeps the seed it was drawn with, so a selection can be re-checked years later. Safety
and compliance staff use the page to run draws on schedule and track who has been tested.

## Tasks

### Set up a testing pool
Keywords: new random pool, testing rates, add pool
1. Open [Random testing](/hr/random-testing).
2. Select **New pool** in the **Pools** panel.
3. Fill in **Code**, **Name**, an optional **Description**, **Status**, how often to
   **Draw every**, the **Drug rate (% a year)** and **Alcohol rate (% a year)**.
4. Tick the **Driver types** to include, or leave them all clear to include every
   safety-sensitive driver. Turn on **Default pool** if it should be the main one.
5. Select **Create**. To change it later, select **Edit** on the pool.

### Run a random draw
Keywords: draw names, select drivers for testing, quarterly draw
1. Open [Random testing](/hr/random-testing).
2. On the pool, select the draw button. It reads **Run draw**, or names the period that is owed.
3. The new round opens as a draft showing who was selected for drug and alcohol testing.

### Finalise or void a round
Keywords: confirm selection, cancel draw, redraw
1. Open [Random testing](/hr/random-testing) and find the draft round under **Rounds**.
2. Select **Finalise** and confirm to make the names the record for that period, or **Void** and
   **Void the round** to discard the selection so the period can be drawn again.

### Track the selected drivers
Keywords: notify driver, excuse driver, missed test
1. Open [Random testing](/hr/random-testing) and select **Open** on the round.
2. For each selected driver, select **Mark notified** once told, or **Excuse** or **Missed** as
   appropriate.
3. To see only one pool's rounds, select **Rounds** on the pool; filter by status with **All**,
   **Draft**, **Final** or **Voided**.

## Notes
- The page appears only for organizations that run their own assets (asset operations) and needs
  read access to DOT random pools. Creating pools needs create access, editing needs update
  access, and drawing, finalising, voiding and updating selections need manage access.
- Once a round is final, correcting a name means voiding the whole round. A voided round stays on
  file with its seed so the audit trail shows it happened.
