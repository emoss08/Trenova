## What it's for
The welcome wizard is the first thing a new Trenova Cloud organization sees after its owner
verifies their email. It collects the company profile, asks how the company moves freight, and
offers to load sample data, then opens the app. Until it is finished, every page sends you back
to it. It never appears on a self-hosted installation.

## Tasks

### Finish setting up a new organization
Keywords: complete onboarding, company profile, first time setup
1. Under **Company profile**, enter **Company name**, **Timezone**, **Street address**, **City**,
   **State** and **ZIP code**. **SCAC code** and **DOT number** are optional.
2. Select **Continue**, then choose an **Operation type**: **Asset carrier** if you run your own
   trucks, **Freight brokerage** if you arrange freight with outside carriers, or **Both**.
3. Select **Continue**. Leave **Load sample data** on to start with a few customers, locations,
   equipment and shipments, or turn it off to start empty.
4. Select **Continue**, check the summary, and select **Finish setup**.

### Change an answer before finishing
Keywords: go back, edit setup, fix company name
1. Select **Back** to return to an earlier step, or select **Edit** beside a section on the review
   step.
2. Change the answer and select **Continue** until you reach the review step again.

## Notes
Everything the wizard sets can be changed later in
[Organization settings](/admin/organization-settings). Sample records count toward the free demo's
limits like any other record and can be deleted at any time; see [Plan & usage](/admin/plan-usage).
