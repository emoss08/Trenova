## What it's for
Fleet codes divide your drivers and equipment into fleets, each with a manager. A fleet code has a **Code**, **Status**, **Manager**, optional **Description** and **Color**, and optional **Revenue goal** and **Deadhead goal** figures for the fleet. Operations managers and administrators set them up; workers and equipment are then assigned to a fleet.

## Tasks

### Add a fleet code
Keywords: new fleet, create fleet code
1. Open [Fleet codes](/dispatch/configuration-files/fleet-codes).
2. Select **New fleet code**.
3. Choose a **Status**, fill in **Code** and pick the **Manager**.
4. Optionally add a **Description**, **Revenue goal**, **Deadhead goal** and **Color**.
5. Select **Save**.

### Edit a fleet code
Keywords: change fleet manager, update fleet goals
1. Open [Fleet codes](/dispatch/configuration-files/fleet-codes).
2. Select the row, or right-click it and choose **Edit**.
3. Change the fields and select **Save**.

### Activate or deactivate several fleet codes
Keywords: bulk status, inactivate fleet codes
1. Open [Fleet codes](/dispatch/configuration-files/fleet-codes).
2. Tick the rows to change.
3. Select **Update status** in the bar that appears and choose **Active** or **Inactive**.

## Notes
The page appears only for organizations that run their own assets (asset operations). Adding needs create permission for fleet codes; editing needs update permission.
