## What it's for
Location categories group your locations by what kind of place they are. Each category has a **Name**, a **Type**, an optional **Facility type**, **Description** and **Color**, and amenity flags: **Requires appointment**, **Allows overnight**, **Has restroom** and **Secure parking**. Each location on [Locations](/dispatch/locations) can be given a category, so dispatchers can tell at a glance what to expect at a stop.

## Tasks

### Add a location category
Keywords: new location category, create facility type
1. Open [Location categories](/dispatch/configuration-files/location-categories).
2. Select **New location category**.
3. Fill in **Name** and choose a **Type**. Optionally choose a **Facility type** and add a **Description** and **Color**.
4. Turn on the amenity switches that apply: **Requires appointment**, **Allows overnight**, **Has restroom**, **Secure parking**.
5. Select **Save**.

### Edit a location category
Keywords: change location category, update amenities
1. Open [Location categories](/dispatch/configuration-files/location-categories).
2. Select the row, or right-click it and choose **Edit**.
3. Change the fields and select **Save**.

## Notes
Adding needs create permission for location categories; editing needs update permission.
