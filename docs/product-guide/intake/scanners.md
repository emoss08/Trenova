## What it's for
My scanners lists the computers you have paired with Trenova Capture, the Windows companion that scans and prints into Trenova. Each one shows whether it is online, which scanners it can reach, and its Trenova Capture version. A paired computer acts as you: it can only file what you could file yourself, and it stops working if it is revoked or your access changes.

Pairing happens on the pairing page, where you approve the code Trenova Capture shows.

## Tasks

### Pair a computer
Keywords: set up scanner, connect Trenova Capture, sign in the companion, approve code
1. On the computer your scanner is plugged into, open [My scanners](/capture/devices), select **Download Trenova Capture** and run the installer (it needs administrator rights). Then open Trenova Capture from the Start menu, or select its icon in the notification area, and choose Sign in. It shows an eight-letter code and opens the pairing page.
2. If the page did not open, open [My scanners](/capture/devices), select **Enter a pairing code**, type the code and select **Look up**.
3. Check that **The computer asking** is the one in front of you, change **Name it** if you like, and select **Approve**.

### Scan without opening Trenova
Keywords: scan to intake, tray menu, scan from the computer, quick scan, stop a scan
1. On the paired computer, open Trenova Capture: select its icon in the notification area, or find it in the Start menu.
2. Under Scan to Intake, pick the scanner and its settings (the organization's default is marked), and choose Scan.
3. The window counts the pages as they arrive; Stop ends the scan early and sends what was scanned. A notification says how many pages were sent; select it to open them in [Intake](/intake).

### Print a document into Trenova
Keywords: print to Trenova, virtual printer, print from any program, print a PDF, print into a shipment, print into a record
1. In any program on the paired computer, choose Print and pick the printer named Trenova.
2. Trenova Capture sends what you printed, and a notification says how many pages arrived. It goes to [Intake](/intake), or to the record where you first chose **Print into this record** from the menu beside **Scan** on its Documents tab.
3. If you are signed out of Trenova Capture, the print waits on the computer and is sent when you sign in.

### Carry on after a paper jam
Keywords: jam, double feed, cover open, scanner stopped, continue scanning
1. Trenova Capture opens and says what stopped the scanner. The pages scanned before it stopped are kept on the computer.
2. Clear the scanner, then choose Continue scanning to add the rest to the same stack, or Finish and send to send what was scanned as it is.

### Deal with something that was not sent
Keywords: not sent, refused upload, failed upload, send again, save a copy, discard scan
1. Open Trenova Capture. What Trenova refused is listed under Not sent, with the reason.
2. Choose Send again to send it to [Intake](/intake) as a new stack, or Save a copy to write its pages as PDFs to your Downloads folder, so you can upload them another way.
3. When you no longer need it, choose Discard and confirm. Its pages are deleted from the computer for good.

### Stop a computer from scanning as you
Keywords: lost laptop, remove scanner, unpair, revoke device
1. Open [My scanners](/capture/devices).
2. Select **Revoke** beside the computer, optionally say why, and select **Revoke** again. It stops at once; pages it already sent stay in [Intake](/intake).

## Notes
Pages wait on the computer, encrypted, until Trenova has them, so scanning works while the network is down and nothing is lost if the computer restarts; the Trenova Capture window shows what is waiting and why. A notification you missed is kept under Messages in the window. Choosing Sign out from the icon revokes the computer, as **Revoke** does here. Scanning and printing into Trenova must be turned on for the organization, and you need permission to capture documents, before a computer can be approved. A code lasts ten minutes; start again from the tray icon for a new one. The Trenova printer is added when Trenova Capture is installed, and only the person who printed a document can send it: another person signed in to the same computer never sees it. Only approve a computer you are using: once paired it uploads documents as you.
