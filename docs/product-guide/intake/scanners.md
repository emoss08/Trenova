## What it's for
My scanners lists the computers you have paired with Trenova Capture, the Windows companion that scans and prints into Trenova. Each one shows whether it is online, which scanners it can reach, and its Trenova Capture version. A paired computer acts as you: it can only file what you could file yourself, and it stops working if it is revoked or your access changes.

Pairing happens on the pairing page, where you approve the code Trenova Capture shows.

## Tasks

### Pair a computer
Keywords: set up scanner, connect Trenova Capture, sign in the companion, approve code
1. On the computer your scanner is plugged into, install Trenova Capture and choose Sign in from its tray icon. It shows an eight-letter code and opens the pairing page.
2. If the page did not open, open [My scanners](/capture/devices), select **Enter a pairing code**, type the code and select **Look up**.
3. Check that **The computer asking** is the one in front of you, change **Name it** if you like, and select **Approve**.

### Scan without opening Trenova
Keywords: scan to intake, tray menu, scan from the computer, quick scan
1. On the paired computer, select the Trenova Capture icon in the notification area.
2. Choose Scan to intake, then the scanner, then the scan profile (the organization's default is marked).
3. When the scan finishes, a notification says how many pages were sent; select it to open them in [Intake](/intake).

### Carry on after a paper jam
Keywords: jam, double feed, cover open, scanner stopped, continue scanning
1. Clear the scanner. The pages scanned before it stopped are kept on the computer.
2. From the Trenova Capture icon, choose Continue scanning to add the rest to the same stack, or Finish to send what was scanned as it is.

### Stop a computer from scanning as you
Keywords: lost laptop, remove scanner, unpair, revoke device
1. Open [My scanners](/capture/devices).
2. Select **Revoke** beside the computer, optionally say why, and select **Revoke** again. It stops at once; pages it already sent stay in [Intake](/intake).

## Notes
Pages wait on the computer, encrypted, until Trenova has them, so scanning works while the network is down and nothing is lost if the computer restarts; the icon's menu shows how many are waiting. Choosing Sign out from the icon revokes the computer, as **Revoke** does here. Scanning and printing into Trenova must be turned on for the organization, and you need permission to capture documents, before a computer can be approved. A code lasts ten minutes; start again from the tray icon for a new one. Only approve a computer you are using: once paired it uploads documents as you.
