## What it's for
Explore opens a saved report or a gallery report as a live result you can read on screen before exporting it. It shows the report's rows in a **Table** view and one view per chart the report defines, lets you filter the rows and choose which **Columns** show, and lets you drill into an aggregated number to see the records behind it. If the report takes values (such as a date range or customer), you fill them in at the top.

## Tasks

### Explore a report
Keywords: open report, look at report results, see report on screen
1. Open the [Report library](/reports) and select a report card (or **Explore** on a **Gallery** card).
2. Fill in any values the report asks for across the top.
3. Switch between **Table** and the report's charts. Type in **Filter these rows...** to narrow what shows, and use **Columns** to hide or show columns.

### See the records behind a number
Keywords: drill through, which records make up this total
1. Explore the report from the [Report library](/reports).
2. Select an aggregated value in the results. **Records behind this number** opens with the individual records that value was built from.

### Export what you are looking at
Keywords: download report, export to Excel, CSV
1. Explore the report from the [Report library](/reports).
2. Select **Export**, choose the **Format**, and select **Run report**. The file is ready in [Run history](/reports/runs).

### Change the report
1. Explore a saved report from the [Report library](/reports) and select **Edit** to open it in the [report builder](/reports/builder).

## Notes
Needs read access to reports. Gallery reports cannot be edited directly; customize them from the **Gallery** tab first. When the results show "row limit reached", the report returned more rows than it displays; export it to get them all.
