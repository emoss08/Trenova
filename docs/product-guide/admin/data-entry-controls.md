## What it's for
Data entry control sets how text is formatted automatically when people enter data, so codes,
names, email addresses and cities look the same everywhere. The page has one card, **Case
formatting rules**, with four settings.

Administrators use it once when setting up the organization and whenever they want to change the
house style for entered text.

## Tasks

### Change how entered text is capitalized
Keywords: uppercase, lowercase, title case, as entered
1. Open [Data entry controls](/admin/data-entry-controls).
2. In **Case formatting rules**, choose a format for each field type:
   - **Code case** for code fields such as equipment and fleet codes.
   - **Name case** for name fields such as commodity and hazmat names.
   - **Email case** for email addresses.
   - **City case** for city names.
3. The formats are **As entered**, UPPER, lower and **Title case**.
4. Select **Save changes**.

## Notes
Opening the page needs read access to data entry control; saving needs update access. The rules
apply system-wide.
