## What it's for
Shipment types are the categories your organization puts shipments into, such as a kind of freight or load. Each type has a **Code**, a **Description**, an optional **Color** and a **Status**. Shipments pick a shipment type, so this list is set up by an administrator or operations lead and kept short.

## Tasks

### Add a shipment type
Keywords: create shipment type, new load type
1. Open [Shipment types](/shipment-management/configuration-files/shipment-types).
2. Select **New shipment type**.
3. Choose a **Status**, fill in **Code**, and optionally a **Description** and **Color**.
4. Select **Save**. Use the arrow on the save button to pick **Save & close** or **Save & add another** instead.

### Edit a shipment type
Keywords: change shipment type, rename shipment type
1. Open [Shipment types](/shipment-management/configuration-files/shipment-types).
2. Select the row to open it in the side panel, or right-click the row and choose **Edit**.
3. Change the fields and select **Save**.
4. To change only the **Code** or **Description**, hover the cell in the table and select its pencil icon to edit it in place.

### Activate or deactivate several shipment types
Keywords: bulk status, inactivate shipment types
1. Open [Shipment types](/shipment-management/configuration-files/shipment-types).
2. Tick the rows to change.
3. In the bar that appears, select **Update status** and choose **Active** or **Inactive**.

### Find a shipment type
Keywords: search shipment types, filter shipment types
1. Open [Shipment types](/shipment-management/configuration-files/shipment-types).
2. Type in the search box, or select **Filter** to add conditions on columns such as **Status**.

## Notes
Adding a shipment type needs create permission for shipment types, and editing needs update permission; without update permission the row opens read-only.
