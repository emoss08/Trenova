## What it's for
Commodities describe the goods your organization hauls: name and description, NMFC freight class, a linked hazardous material if the goods are hazmat, weight and linear feet per unit, maximum quantity per shipment, temperature range, and handling notes such as stackable, fragile and loading instructions. Shipments list the commodities they carry, so these records feed weight, hazmat and temperature handling on the load.

## Tasks

### Add a commodity
Keywords: new commodity, create product, add freight item
1. Open [Commodities](/shipment-management/configuration-files/commodities).
2. Select **New commodity**.
3. Fill in **Status**, **Name** and **Description**.
4. Optionally set **Freight class** and link a **Hazardous material**, then fill in **Weight per unit**, **Linear feet per unit**, **Max qty per shipment**, **Min temperature**, **Max temperature**, **Stackable**, **Fragile** and **Loading instructions**.
5. Select **Save**.

### Edit a commodity
Keywords: change commodity, update freight class
1. Open [Commodities](/shipment-management/configuration-files/commodities).
2. Select the row, or right-click it and choose **Edit**.
3. Change the fields and select **Save**.

### Activate or deactivate several commodities
Keywords: bulk status, inactivate commodities
1. Open [Commodities](/shipment-management/configuration-files/commodities).
2. Tick the rows to change.
3. Select **Update status** in the bar that appears and choose **Active** or **Inactive**.

## Notes
The hazardous material you link must already exist on [Hazardous materials](/shipment-management/configuration-files/hazardous-materials).

Adding needs create permission for commodities; editing needs update permission.
