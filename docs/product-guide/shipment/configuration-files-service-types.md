## What it's for
Service types are the levels of service your organization offers on a shipment. Each service type has a **Code**, a **Description**, an optional **Color** and a **Status**, and shipments pick one. Administrators and operations leads maintain the list.

## Tasks

### Add a service type
Keywords: create service type, new service level
1. Open [Service types](/shipment-management/configuration-files/service-types).
2. Select **New service type**.
3. Choose a **Status**, fill in **Code**, and optionally a **Description** and **Color**.
4. Select **Save**, or pick **Save & close** or **Save & add another** from the arrow on the save button.

### Edit a service type
Keywords: change service type, rename service level
1. Open [Service types](/shipment-management/configuration-files/service-types).
2. Select the row to open it in the side panel, or right-click it and choose **Edit**.
3. Change the fields and select **Save**.
4. To change only the **Code** or **Description**, hover the cell in the table and select its pencil icon to edit it in place.

### Activate or deactivate several service types
Keywords: bulk status, inactivate service types
1. Open [Service types](/shipment-management/configuration-files/service-types).
2. Tick the rows to change.
3. Select **Update status** in the bar that appears and choose **Active** or **Inactive**.

## Notes
Adding a service type needs create permission for service types, and editing needs update permission.
