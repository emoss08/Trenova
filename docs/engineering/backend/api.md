# APIs: GraphQL and REST

GraphQL is the API the client reads and writes through; REST serves files, webhooks, public
token links, streams and integrations that are not a query over records. Paths are under
`services/tms/`. Read [graphql-executor.md](../graphql-executor.md) before changing the generator
or runtime and [generated-artifacts.md](../generated-artifacts.md) before changing a schema.

## GraphQL schema

- Schema files are `internal/api/graphql/schema/*.graphqls`; regenerate with `task gqlgen`, never
  `go tool gqlgen generate` (it writes gqlgen's single-package executor and breaks the build).
- Scalars from `shared.graphqls`: `Timestamp` for Unix-second instants (never `Int` for a
  `*At`/`*Date` field), `Decimal` for money and exact quantities (never `String` or `Float`).
- Bind an enum to its domain type in `gqlgen.yml` when the values match, rather than writing a
  conversion resolver.
- An initialism in a domain field (`ShipmentBOL`, `DOTNumber`) goes in `go_initialisms` in
  `gqlgen.yml`, 3+ letters only; two-letter ones (`AR`, `PO`) mangle enum constants and keep a
  per-field `fieldName:` override.
- Patch inputs (`XPatchInput`) mark fields `@goField(omittable: true)`: absent leaves the value,
  explicit `null` clears it. Mappers are generated by `resolver/mappergen`; hand-written
  exceptions go in `resolver/mappers.yml`.
- `projection.yml` must resolve every field to a column, a relation or a declared virtual.
- Every field a client reads is either on the entity's row, batched through a loader, or
  computed from those. A field that costs a query per row is a defect.
- Breaking the schema is allowed (we have not launched and every client is ours): change the
  client in the same PR and take the `graphql-breaking-approved` label. `task gqlschema-diff`
  reports the break.

## Resolvers

One package per schema file, `resolver/<file>resolver/`, with a generated `Deps` holding
`*base.Core` and only the services its code names. To add a dependency, add it to `Params`,
`Services` and `newServices` in `resolver/services.go`, use it as `r.X` and run `task gqlgen`.
Resolver packages never import each other; shared code goes in `base` only when it needs nothing
but `Core`.

- **Authorize first.** A root resolver starts with
  `authCtx, err := r.RequirePermission(ctx, permission.ResourceX, permission.OpY)` and scopes with
  `base.TenantInfo(authCtx)`. `authzlint` (`TestEveryRootResolverIsAuthorized`) fails a root
  resolver that does not reach a check; an authentication-only one is listed in
  `authOnlyAllowlist` with a reason. Self-scoped operations are named `My<Thing>` and listed in
  `selfscoped.Resolvers` under the reason they touch only the caller's records.
- **Lists are connections.** `base.DataTableConnectionFromGraphQL` → the service's
  `ListConnection` with `projection.Select(...)` columns → `base.EntityCursorConnection`
  (`commodityresolver/commodity.resolvers.go`). `IncludeTotalCount` is set only when `totalCount`
  or `totalCountExact` is selected (`base.ConnectionTotalRequested`), and every connection type
  declares `totalCountExact: Boolean!` beside `totalCount`.
- **Mutations** map input to the domain with the generated mappers, take the actor from
  `actorutil.FromAuthContext(authCtx)`, and call the same service method an agent tool calls
  (`trailerresolver/trailer.resolvers.go`).
- **Per-parent reads go through a dataloader**, never a single-ID getter from an object-type
  resolver. Loaders live in `internal/api/graphql/loaders` (`batchByIDFunc`, `batchCountFunc`,
  `batchGroupFunc`) over a repository `...ByIDs` method. Register the factory in
  `loaders/loaders.go` and `bootstrap/modules/api/graphql.go`, add its field to `set` and its
  accessor and `Attach` to `loaders/access.go`; resolvers read through the accessors
  (`loaders.Available(ctx)`, `loaders.CustomerByID(ctx, id)`). No exported type or function in
  `loaders` mentions `dataloadgen.Loader`. A per-parent count goes through one too, and every field that shows it
  (`laneCount`, `laneCountExact`) reads the same loader, so they share one read: the repository
  counts every requested parent in one statement, a lateral `LIMIT` capping each at its share of
  `pagination.ExactTotalUpTo` (`ExactTotalUpTo / parents`, at least 100), and estimates only the
  parents past their cap (`rateagreementrepository.CountLiveLanes`). A stored count suits only a
  figure that does not depend on the clock; lane liveness does, so lanes are counted at read. A
  per-parent list with an argument (`lanes(first:)`) loads through `batchFirstFunc`: the key
  carries the argument (`firstKey(id, first)`), each distinct `first` is one read for every parent
  asking it, and the repository reads them in one statement, `id IN (SELECT child.id FROM parents
  CROSS JOIN LATERAL (… ORDER BY … LIMIT first))`, bounded by parents times `first`
  (`rateagreementrepository.ListFirstLanes`). It counts nothing; a total is its own field on the
  count loader.
- **Another kind's record** on a type shows its reference view; more needs
  `@requiresRead(kind:)` ([reference-views.md](../reference-views.md)).
- Tests build `&QueryResolver{&Deps{Core: &base.Core{...}, ...}}`.

## Transport limits

Clients send persisted operations by hash only (outside production the server re-reads
`persisted-documents.json`, so run `pnpm --filter @trenova/graphql codegen` after editing an
operation). `/graphql` enforces a body limit, a static cost and depth ceiling
(`querycost.MaxOperationCost`, `MaxOperationDepth`) and a per-user cost budget
(`security.graphql.*`, `gqlext.NewCostBudgetExtension`). A new expensive field declares its cost
rather than raising the ceiling.

## REST handlers

`internal/api/handlers/<name>handler/` (`commodityhandler/handler.go` is the model):

- fx `Params`, `New(p)`, `RegisterRoutes(rg *gin.RouterGroup)`; each route wraps
  `h.pm.RequirePermission(permission.ResourceX.String(), permission.OpY)`.
- The caller from `authctx.GetAuthContext(c)`; bodies through `authctx.BindJSON(c, authCtx, &v)`,
  which also sets tenant info; large bodies through `helpers.ReadBoundedRequestBody`.
- Every error through `h.eh.HandleError(c, err)`, which maps `errortypes` to status codes.
- Lists go through `pagination.List` (cursor response: `count`, `totalCount`) or
  `pagination.SelectOptions` (`count`, offset `next`); both carry `totalCountExact` from
  `ListResult.TotalExact`, and a select-options `next` comes from `pagination.HasMore`, so an
  estimated total never ends or extends the pages. A response built by hand from a `ListResult`
  carries `totalExact` beside `total`, as does a GraphQL list type with a `total` or `totalCount`
  (`totalExact`/`totalCountExact: Boolean!`).
- Register the constructor in `bootstrap/modules/api/handlers.go` and call `RegisterRoutes` from
  `internal/api/router.go`. The protected group already applies auth, read scope, rate limiting
  by principal, CSRF, the read-only guard and idempotency; a public route (token links,
  webhooks) applies its own rate limit (`ByPublicToken`, `ByClientIP`) and verifies its token or
  signature (`shared/webhooksig`) before reading anything.
- Edition routes join through `internal/api/routegroup`, never by editing `router.go` from Cloud.
- Every write route needs write coverage ([agent-write-coverage.md](../agent-write-coverage.md)).
