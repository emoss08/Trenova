This guide describes Kestrel Valve Works, the manufacturer partner that dev/edi-partner-sim
plays (partners/manufacturer). Upload it to a Desk conversation with an agent that handles EDI
and ask for the connection to be set up from it; the draft should match the simulator's
defaults below. Start the simulator first (task sim in dev/edi-partner-sim).

2. Communications
2.1 AS2
Kestrel exchanges documents over AS2.
Kestrel AS2 Identifier: KESTRELVW
Carrier AS2 Identifier: TRENOVA
AS2 URL: http://localhost:9210/as2/manufacturer
MDN: synchronous, signed.
Signing algorithm: SHA-256. Encryption algorithm: AES-256 (CBC). Compression: none.
Kestrel's public certificate is served at http://localhost:9210/control/manufacturer.
Your private key and certificate stay with you; enter them on the communication profile.
2.2 SFTP mailbox
Kestrel also runs an SFTP mailbox for the mailbox pickup path.
SFTP host: localhost, port 9222, user manufacturer.
Kestrel drops files for the carrier in /inbound and collects the carrier's files from /outbound.
The SFTP password is the one the simulator was started with (--sftp-password); it is not
given here. The host key is served at http://localhost:9210/control/manufacturer.

ISA05/ISA06 Kestrel interchange sender: qualifier ZZ (mutually defined), ID KESTRELVW
ISA07/ISA08 Carrier interchange receiver: qualifier ZZ (mutually defined), ID TRENOVA
ISA11 repetition separator: ^ (caret). ISA12 version 00401. ISA15 usage indicator: T.
3.2 Functional group (GS)
GS02 Application Sender Code: KESTRELVW
GS03 Application Receiver Code: TRENOVA
GS08 Version: 004010
3.3 Delimiters
Element separator: * (asterisk). Segment terminator: ~ (tilde). Sub-element separator: > (greater than).
Kestrel writes a line feed after every segment terminator.
3.4 Control numbers
Carrier interchange control numbers (ISA13) start at 1 and increase by one.

4. Transaction sets
4.1 Documents exchanged
Kestrel sends the 204 Motor Carrier Load Tender to the carrier.
The carrier answers each tender with a 990 Response to a Load Tender.
The carrier sends the 214 Transportation Carrier Shipment Status Message for pickups and deliveries.
The carrier bills each load with a 210 Motor Carrier Freight Details and Invoice.
4.2 Acknowledgments
Kestrel returns a 997 Functional Acknowledgment for every transaction set it receives.
The carrier returns a 997 for every 204. The 999 Implementation Acknowledgment is not used.
Kestrel acknowledges within 45 seconds and rejects (AK5 R) any transaction that breaks this guide.

5. 204 Load Tender requirements
B2 Beginning Segment is mandatory. B2-02 Standard Carrier Alpha Code is TRNV. B2-04 Shipment Identification Number is mandatory: the Kestrel load number, KVW- and six digits. B2-06 Shipment Method of Payment: PP Prepaid or TP Third Party Pay.
B2A Set Purpose is mandatory. B2A-01 codes: 00 Original, 01 Cancellation, 04 Change, 05 Replace. B2A-02 is LT (load tender).
L11 with qualifier BM (Bill of Lading Number) is mandatory. L11 with qualifier PO (Purchase Order Number) is optional.
NTE with qualifier LOI (Loading Instructions) is optional.
N1 with qualifier BT (Bill-to-Party) is mandatory, identified by qualifier 93 (code assigned by the party originating the transaction), with N3 and N4.
N7 Equipment Details is mandatory: N7-11 equipment code TF (trailer, dry freight), FT (flat bed trailer) or RT (refrigerated trailer); N7-13 the reefer set point in degrees Fahrenheit; N7-15 the equipment length in feet and inches.
S5 Stop Off Details is mandatory for every stop. S5-02 codes: LD Load, UL Unload. S5-03 weight in pounds, S5-05 pieces.
L11 with qualifier P8 (Pickup Reference Number) or AO (Appointment Number) is optional on a stop.
G62 is mandatory twice on every stop: qualifiers 37 (ship not before) and 38 (ship not later than) on a pickup, 53 (deliver not before) and 54 (deliver not later than) on a delivery, with the time and its time code (CT, ET, MT, PT).
AT8 Shipment Weight, Packaging and Quantity Data is mandatory on every stop.
N1 is mandatory on every stop: SH (shipper) on a pickup and CN (consignee) on a delivery, identified by qualifier 93, with N3 and N4. G61 Contact is optional.
L5 Description, Marks and Numbers and AT8 describe every commodity line on a pickup. A hazardous line adds LH1, LH2 and LH3.
L3 Total Weight and Charges is mandatory.
