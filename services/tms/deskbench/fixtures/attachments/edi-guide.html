2. Communications

2.1 Connection method

Acme exchanges all documents over AS2 (Applicability Statement 2). FTP and VAN connections are not offered.

Acme AS2 Identifier: ACMERETAILAS2
Carrier AS2 Identifier: TRENOVA-AS2

Production AS2 URL: https://as2.acmeretail.example/as2/receive
Test AS2 URL: https://as2-test.acmeretail.example/as2/receive

MDN: synchronous, signed.
Signing algorithm: SHA-256. Encryption algorithm: AES-256 (CBC).

2.2 Certificates

Certificates are exchanged by email with the EDI Coordinator before testing starts.

For the test environment, the keystore password: Acme#Test2026 is sent separately.

Begin in the test environment; Acme moves the connection to production after certification.

4. Transaction sets

4.1 Documents exchanged

Acme sends the 204 Motor Carrier Load Tender to the carrier.

The carrier answers each tender with a 990 Response to a Load Tender within 2 hours.

The carrier sends the 214 Transportation Carrier Shipment Status Message for every pickup and delivery.

The carrier invoices with the 210 Motor Carrier Freight Details and Invoice.

4.2 Acknowledgments

Acme expects a 997 Functional Acknowledgment for every 990, 214 and 210 within 4 hours.

Acme returns a 997 for each document it receives. Acme does not support the 999 Implementation Acknowledgment.

5. 204 Load Tender requirements

B2 Beginning Segment is mandatory. B2-02 Standard Carrier Alpha Code is mandatory. B2-04 Shipment Identification Number is mandatory.

B2A Set Purpose is mandatory. B2A-01 codes: 00 Original, 01 Cancellation, 04 Change.

L11 with qualifier BM (Bill of Lading) is mandatory.

S5 Stop Off Details is mandatory for every stop.

6. 214 Shipment Status requirements

AT7 Shipment Status Details is mandatory. AT7-01 codes: X3 Arrived at Pickup, AF Departed Pickup, X1 Arrived at Delivery, D1 Delivered.

{{MS1_RULE}}

K1 Remarks is not used.

7.2 Service levels (L5): STD Standard, EXP Expedited.
